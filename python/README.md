# K1 Cipher

برنامهٔ دسکتاپی ساده برای رمزگذاری و رمزگشایی متن با گذرواژه. می‌توانید متن رمز‌شده را کپی کنید، به شکل QR به اشتراک بگذارید یا در فایل `.k1c` ذخیره کنید.

## امکانات

- رمزگذاری و رمزگشایی متن با گذرواژه
- ذخیره و بازکردن فایل‌های `.k1c`
- نمایش متن رمز‌شده به صورت QR و کپی آن برای اشتراک‌گذاری
- سازگاری قالب رمزگذاری با نسخهٔ اندروید K1 Cipher
- بازشدن پنجره در مرکز صفحه
- فایل اجرایی مستقل ویندوز

## دریافت و اجرا در ویندوز

فایل اجرایی را از پوشهٔ `dist` دریافت کنید:

```text
dist/K1 Cipher.exe
```

برای استفاده از فایل اجرایی، نصب پایتون لازم نیست.

## اجرا از روی کد منبع

به Python و کتابخانه‌های نوشته‌شده در `requirements-1.txt` نیاز دارید. در پوشهٔ پروژه اجرا کنید:

```bash
python -m pip install -r requirements.txt
python k1cipher.py
```

برای بازکردن مستقیم یک فایل رمز‌شده:

```bash
python k1cipher.py path/to/file.k1c
```

## راهنمای استفاده

1. متن موردنظر را در کادر بالایی وارد یا جای‌گذاری کنید.
2. **ENCRYPT** را بزنید و گذرواژه‌ای با حداقل ۸ نویسه وارد و تأیید کنید.
3. متن رمز‌شده در کادر پایینی نمایش داده می‌شود. آن را کپی کنید، با **Share** به شکل QR نمایش دهید یا با **SAVE** در فایل ذخیره کنید.
4. برای رمزگشایی، متن رمز‌شده را در یکی از کادرها قرار دهید یا فایل `.k1c` را با **READ FILE** باز کنید. سپس **DECRYPT** را بزنید و همان گذرواژه را وارد کنید.
5. با **CLEAR** هر دو کادر را پاک کنید.

## جزئیات رمزگذاری

- مشتق‌سازی کلید: **Argon2id**، نسخهٔ ۱٫۳، با حافظهٔ ۶۴ مگابایت و ۳ مرحله
- رمزنگاری: **AES-256-GCM**
- برای هر پیام، salt شانزده‌بایتی و nonce دوازده‌بایتی تصادفی تولید می‌شود.
- گذرواژه در فایل رمز‌شده ذخیره نمی‌شود. آن را در جای امن نگه دارید؛ در صورت فراموشی، بازیابی متن ممکن نیست.

## ساخت فایل اجرایی ویندوز

پس از نصب وابستگی‌های برنامه و PyInstaller، دستور زیر را در پوشهٔ پروژه اجرا کنید:

```bash
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "K1 Cipher" k1cipher.py
```

فایل خروجی در مسیر `dist/K1 Cipher.exe` ساخته می‌شود.
